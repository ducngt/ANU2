# V5.1 Direct Speech and Human-AI Request Flow

Human -> voice/text + attachments -> governed Artifact -> Work Item request -> delegated AI actor(s) -> model runtime -> evidence/output -> human checkpoint.

Speech is converted to text with the browser Web Speech API when available. The transcript is persisted as a text Artifact for provenance. Attached text-like files (TXT/MD/CSV/JSON) are extracted in-browser and passed into the model context. Binary formats are not silently interpreted in V5.1; they remain governed Artifacts until a dedicated document/vision/audio/video processor is connected.
