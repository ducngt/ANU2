# ANU2 V5.2 — Multimodal Processing Runtime

V5.2 turns Artifact intake into a processing runtime used inside authorized Human–AI work.

## Human input
- Text
- Direct speech through browser Speech Recognition when available
- TXT/MD/CSV/JSON
- PDF/Office documents
- Images
- Audio
- Video

## Processing contract
1. Human supplies a request and/or files.
2. Files become governed Artifacts with provenance.
3. AI may read/process an Artifact only inside a Work Item with an active assignment whose delegated actions permit READ/READ_FILE/ANALYZE.
4. Processor output is stored back on the Artifact as extractedText/textPreview plus provider/model metadata.
5. Agents consume processed Artifact content through the existing Work Item runtime.
6. Master-data commit remains a Human checkpoint.

## Provider behavior in browser trial runtime
- Local text: TXT/MD/CSV/JSON are extracted without a provider.
- Gemini: inline multimodal analysis for PDF/image/audio/video and other MIME types supported by the selected model.
- OpenAI/OpenRouter/OpenAI-compatible: image analysis through vision-capable chat models.
- OpenAI: uploaded audio transcription uses `gpt-4o-mini-transcribe`.
- Unsupported provider/media combinations fail explicitly; there is no silent mock fallback.

GitHub Pages remains an experimental browser runtime. Binary file bytes are retained only in the current tab session. Production requires secure object storage and a backend multimodal gateway.
