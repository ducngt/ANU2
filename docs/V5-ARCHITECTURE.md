# ANU2 V5.0

V5.0 restores Domain Intelligence as first-class architecture while preserving one University Core and one Intelligence Fabric.

## Domain Intelligence
- LIS — Learning Intelligence System
- RIS — Research Intelligence System
- SIS — Student Intelligence System
- PIS — People Intelligence System
- OIS — Organization Intelligence System
- FIS — Finance Intelligence System
- FMS — Facilities Intelligence System

These are not isolated applications. They share Person, Identity, Organization, Role, Authority, Work Item, Artifact, Evidence, Knowledge, Agents, Provenance and University Memory.

## V5 changes
1. Universal data intake accepts structured CSV/JSON and document/image/audio/video artifacts.
2. System Admin Users & Administration supports manual user creation, activate/suspend, password reset, provisioning from imported people and adding role assignments.
3. System administration is a Human-AI work domain: admin can delegate review tasks to governance/data-quality AI actors. AI may analyze/recommend but cannot autonomously grant/revoke authority.
4. Work assignments carry domain, resource scope, data scope, validity and human checkpoint.
5. Existing VI/EN/zh-CN, Rector/Vice Rector whole-university scope, real provider testing, import/master data, audit and multi-role context remain regression requirements.

## Browser limitation
GitHub Pages remains a static trial deployment. Binary artifact bytes are kept only for the current browser session; provenance metadata persists in the browser store. Production must use a secure object store/API gateway and server-side authorization.
